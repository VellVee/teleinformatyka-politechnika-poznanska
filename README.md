# Teleinformatyka (2018–2022)
### Politechnika Poznańska

Repozytorium zawiera zbiór różnorodnych materiałów dydaktycznych i naukowych ze studiów inżynierskich na kierunku **Teleinformatyka** na **Politechnice Poznańskiej** z rocznika **2018–2022**.

---

## 📚 Zawartość repozytorium

W repozytorium znajdują się między innymi:
- **Opracowania** zagadnień do egzaminów, kolokwiów i wejściówek,
- **Pytania i odpowiedzi** oraz bazy pytań testowych (m.in. platforma eKursy),
- **Sprawozdania laboratoryjne** wraz z pomiarami, wykresami i danymi pomiarowymi,
- **Rozwiązania zadań** z ćwiczeń tablicowych oraz zadań domowych/tygodniowych,
- **Kody źródłowe i projekty** (m.in. FPGA / Verilog, programowanie mikroprocesorów ARM / 8051 w asemblerze, symulacje MATLAB, Android, bazy danych SQL, skrypty powłoki),
- **Układy cyfrowe** i schematy logiczne (np. projekty Logisim),
- **Arkusze egzaminacyjne i kolokwialne** z lat ubiegłych (w tym terminy podstawowe, poprawkowe oraz komisyjne),
- **Prezentacje i materiały** z wykładów,
- **Notatki** i materiały pomocnicze.
